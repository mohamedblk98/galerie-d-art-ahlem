# MCP Capability Matrix

Before using MCP, detect actual servers/tools.

| Capability | Needed for | Evidence | Fallback |
|---|---|---|---|
| Browser | web research / inspection | configured browser tool | manual URLs / web search |
| Screenshot | visual QA | screenshot-capable tool | ask user to provide screenshot |
| Design tool | inspect design files | connected design MCP | static spec |
| Image generation | custom visuals | connected image tool | placeholders |
| Blender/3D | 3D editing | configured 3D MCP | code-only changes |
