# Design Gate

Before substantial implementation, verify:
- Product goal and primary user are known.
- Primary task and CTA are defined.
- Page/section hierarchy is defined.
- Key component patterns and states are defined.
- Visual direction exists: color, typography, grid, imagery.
- Responsive strategy exists.
- Motion intent exists or is consciously omitted.
- External references have been researched when beneficial.

A gate can be passed with explicit reasonable defaults when unanswered details are low risk.
