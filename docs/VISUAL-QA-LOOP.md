# Visual QA Loop

1. Build the smallest meaningful implementation.
2. Capture the actual rendered page at representative viewport sizes.
3. Compare against the design brief and decision log.
4. Identify measurable mismatches.
5. Prioritize structural issues before polish.
6. Patch only the highest-value issues.
7. Capture again.
8. Stop when remaining differences are intentional, low-impact, or blocked by missing tooling/assets.

Never invent screenshot evidence.
